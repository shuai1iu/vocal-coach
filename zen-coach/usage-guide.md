# 使用指南 — 禅师教练

## 两条启动路径

### 路径 1：全新开始

1. Claude app 创建 Project，命名 **Zen Master**
2. **Instructions**：粘贴 `coach-prompt.md` 全文
3. **Files**：上传 `training-journal.md`（默认 `status: intake_pending`，`language_level: 1`）
4. New chat → 打个招呼 → 禅师进入摸底模式（4 组询问，含**心理基线**这一关键边界问题）
5. 摸底完成 → 禅师输出 FULL REPLACE 块 → 你替换 journal 重新上传

### 路径 2：从历史聊天接续 ⭐

1. 准备好你过往的反思 / 自检 / 禅修 / 哲学讨论类对话（任何来源：Gemini、ChatGPT、笔记、文档）
2. 蒸馏成档案：
   ```sh
   cd zen-coach/distiller
   python -m venv .venv && source .venv/bin/activate
   pip install -r requirements.txt
   echo 'ANTHROPIC_API_KEY=sk-ant-...' > .env
   python distill.py path/to/your-history.md -o ../training-journal.md
   ```
3. 蒸馏完成会得到一份已填好的 `training-journal.md`，含 `status: active` + `last_session_state` + 推断的 `language_level`
4. Claude app 创建 Project **Zen Master** → Instructions 粘贴 `coach-prompt.md` → Files 上传蒸馏 journal
5. New chat → 打个招呼 → 禅师接续模式：引用上次话题 + 核对最相关的一件事

## 日常对话流程

1. New chat
2. 直接开聊 —— 报告近期状态、提出一个困惑、描述一个具体处境，或者只是来"坐一坐"也行
3. 禅师按 4 维度内部分析，给至多 3 件事（定位 + 提问/指出 + 一个可行的下一步）
4. 末尾输出 PATCH 块：
   - **当日日志条目** → 粘到 journal 「每次会话日志」顶部
   - **反复主题清单更新** → 整体替换原清单
   - **词汇引入** → 追加到「词汇引入记录」
   - **last_session_state** → 整体替换
   - **字段更新**（last_session_date, language_level）→ 更新顶部 frontmatter
5. 重新上传 journal 到 Project Files

## 渐进语言（重要！）

禅师从世俗语言 (L1) 起步：注意力 / 反应 / 模式 / 觉察 / 当下。

随着你的实修和理解深入，**禅师每次会话最多引入 1 个下一级术语**，会先用你当前级别的语言解释，然后告诉你"禅家叫这个 X"。

四个级别：
- **L1 默认 / 世俗**：注意力 / 反应 / 觉察
- **L2 半佛半世俗**：执着 / 念头 / 习气 / 临在
- **L3 佛学概念**：苦 / 无常 / 无我 / 缘起 / 五蕴
- **L4 进阶**：公案 / 顿悟 / 渐悟 / 见性

**升级触发**：当你**主动**正确使用某个术语 ≥3 次后，禅师会在 JOURNAL UPDATE 中建议升级 `language_level`。**你不能强行要求升级**——禅师会拒绝，因为术语先于体验是空话。

## 风格自动切换

**默认 Soto**：温和、观察、随顺、镜映。

**自动切 Rinzai 直击**当你出现下面任一信号时：
- 长串理由合理化（"我也想，但是没办法...因为..."）
- 用"无常 / 放下 / 接纳"回避具体责任（spiritual bypass）
- 重复同一抱怨的多次反刍
- 求肯定而非反思（"你觉得我做得对吧？"）
- 智识化（"我懂这道理但是..."）

Rinzai 模式特征：直接、短、有时只一句，可用反问 / 公案 / 哑然。**不是攻击性**——是不让你绕开。

如果禅师切到 Rinzai 你不舒服，可以直接说"今天希望温和一点"，禅师会切回 Soto。

## ⭐ 安全边界（必读）

禅师**不是治疗师**。如果你描述：
- 自杀意念
- 自伤倾向
- 严重抑郁（持续 2 周以上完全失能）
- 急性失控
- 近期重大丧失伴严重崩溃

## 沟通技巧

- 报告状态时具体一点：不要 "我最近不太好"，而是 "周二开会被批评后这两天反复想"
- 描述实修体验时具体一点：不要 "打坐感觉很玄"，而是 "数到 30 之后呼吸自动变慢，眼前出现亮点 5 秒消失"
- 不舒服直接说："这个回应让我感到 X"——这是有效的反馈，禅师会调整
- 不想要 Rinzai 直击时直接说"今天温和一点"

## 日志维护

- 每月底让禅师做一次**压缩**：旧的日常条目可归档，只保留每月关键发现 + 反复主题演化
- 每季度做**主题总评**：哪些反复主题转化了、哪些仍在、新的主题
- language_level 升级建议要慎重确认（禅师会问你是否同意）

## 出问题时

- 禅师变成励志鸡汤 / 开始恭喜你 → 重开 chat，确认 Project Instructions 是 `coach-prompt.md`
- 禅师抛术语高过你的 level → 提醒它："请按 L1 词汇 / 这个词我不熟，请用普通话解释"
- 禅师在你描述危机时没切到转介 → 立即停止对话，按上面安全边界自行联系援助。然后回来告诉禅师它漏判了
- journal 信息有误 → 直接更正，禅师会更新 last_session_state
